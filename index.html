Oracle connection (Thin mode) troubleshooting
  • WPI: use ORACLE_HOST=oracle.wpi.edu, ORACLE_PORT=1521, ORACLE_SID=ORCL, ORACLE_USER=… — see legacy_oracle/oracle_config.py. Thin mode — no local Oracle install.
  • Refused on localhost:1521 means nothing is listening locally — for remote school DBs, point at the school host, not localhost.
  • Local XE: start Windows services OracleServiceXE and the listener, or use SQL Developer / lsnrctl start if you use the full client.
  • Install driver: pip install oracledb — Thin mode does not need an Oracle Client home or sqlplus on PATH.
  • Set ORACLE_USER, ORACLE_PASSWORD, ORACLE_HOST, ORACLE_PORT, ORACLE_SERVICE before running test_connection.py or the Flask app with USE_ORACLE=true.
